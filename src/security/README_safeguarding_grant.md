# Trusted safeguarding grant

The `safeguarding_officer` role is the only role permitted to issue a safeguarding grant.

A grant must be:
- server-issued;
- tied to one subject person;
- tied to one issuing actor;
- justified by a recorded reason;
- limited to an explicit scope;
- time-limited to at most one hour;
- auditable;
- independently revocable.

A client-supplied `safeguarding: active` value is never sufficient authorization.

Safeguarding access is an exception path for immediate protection/care coordination. It does not permanently change the person's consent state or relationship state.
