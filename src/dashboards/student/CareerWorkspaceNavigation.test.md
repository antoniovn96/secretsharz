# Career Workspace navigation contract

Canonical navigation for every `/dashboard/career/*` page:

- Dashboard
- My Journey (includes assessment)
- My Results
- Career Roadmap
- Reflection Journal
- Book a Session
- My Sessions
- Resources
- Career Games
- My Profile
- Settings

Assessment is intentionally not a primary navigation destination. Legacy assessment routes remain deep-linkable and are treated as part of My Journey until the route migration is complete.
