# Secret Sharz — Career Interest Explorer (RIASEC) V1

**Status:** Original draft instrument specification — NOT validated for production  
**Branch:** rebuild/platform-foundation-v1

## 1. Purpose

The Career Interest Explorer measures preferred activity patterns across six vocational-interest dimensions:

- Realistic (R)
- Investigative (I)
- Artistic (A)
- Social (S)
- Enterprising (E)
- Conventional (C)

It is an exploration tool, not a deterministic career-selection test.

## 2. Target groups

### Explorer
Grades 6–8:
- simpler wording;
- visual response scale may be used;
- report emphasises exploration and experiences.

### Direction
Grades 9–10:
- standard wording;
- report connects interests with subjects, activities and career areas.

### Pathway
Grades 11–12 and early career:
- standard wording;
- report can connect interests with occupations, education pathways and work environments.

The same construct blueprint should be retained while wording and presentation are adapted for age.

## 3. Response model

Preferred response scale:

1 = Would really dislike doing this  
2 = Would probably not enjoy this  
3 = Not sure / might enjoy this  
4 = Would probably enjoy this  
5 = Would really enjoy this

For young users, these labels may be paired with accessible visual anchors.

## 4. Scoring

Ten draft items are assigned to each RIASEC dimension.

For each dimension:
- sum or mean its item responses;
- preserve the raw responses;
- calculate a standardised profile only after pilot/validation rules are established;
- do not use preliminary cut-offs to label a student.

The production scoring model will be decided after pilot analysis.

## 6. Draft item-review checklist

Each item must be reviewed for:
- one clear idea;
- appropriate reading level;
- cultural portability;
- accessibility;
- gender neutrality;
- socioeconomic neutrality;
- absence of career stereotypes;
- absence of specialised prerequisite knowledge;
- construct relevance;
- duplication with another item;
- translation difficulty.

## 7. Initial interpretation direction

The report should identify:
- strongest interest areas;
- secondary areas;
- balanced/mixed profile;
- areas with low expressed preference;
- meaningful pairings;
- exploration ideas.

Do not create fixed career cut-offs in V1.

## 8. RIASEC pairings

The report may use common adjacent/combined patterns as exploration cues, but exact interpretation must be validated.

Possible exploration patterns:
- R + I
- I + A
- A + S
- S + E
- E + C
- C + R

The engine must be able to represent all six dimensions without forcing the student into only one code.

## 9. Pilot requirements

Before production:
- pilot all 60 draft items;
- review missingness and completion time;
- examine item distributions;
- examine subscale reliability;
- inspect item discrimination;
- review potential bias/differential behaviour where sample size permits;
- collect student comprehension feedback;
- revise weak items;
- validate the final scoring/interpretation model.

## 10. Version rule

This document is a draft item bank. No item score, cut-off or career recommendation should be treated as production-validated until the pilot/validation stage is completed.
