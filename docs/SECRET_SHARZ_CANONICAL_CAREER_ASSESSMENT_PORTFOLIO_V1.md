# Secret Sharz — Canonical Career Assessment Portfolio V1

## Source basis

The Career Guidance Module Master Specification v1.0 currently defines **17 independent assessment entries** in section 7.

It also defines two related layers that are **not equivalent to standalone psychometric tests**:

1. Career Narrative / Aspirations — supporting module.
2. Context & Constraints — non-psychometric context layer.

The founder referred to the portfolio as "about 16 tests" during the continuation conversation. No test has been removed or merged because that would require inventing a new founder decision. The implementation therefore preserves the source-defined 17 until the founder explicitly resolves the count discrepancy.

## Commercial rule

All 17 assessments are intended to be independently purchasable, independently scored, independently reportable, and bundle-eligible. Exact item counts, final scoring, norms, calibration and validation remain assessment-development work.

## Founder-approved Career Direction Trio

The standard starter package is:

- Career Interest / RIASEC
- Career Aptitude / Reasoning
- Career Values

Career Decision Readiness is **not** part of the trio. It remains a separate assessment.

## Full Career Intelligence

Full Career Intelligence is intended to combine evidence from the full set of canonical assessments that have been completed and validly scored. It must not fabricate results for modules the person has not taken.

## Implementation status

The current repository only has draft implementations for a subset of modules. The portfolio manifest deliberately separates:

- product scope;
- implementation status;
- psychometric validation status.

A module appearing in the canonical portfolio does not mean it is already a validated instrument.

## Important rule

Do not reduce the portfolio to the five legacy test families that currently exist in parts of the repository. The five-family runtime is an implementation artifact and must be migrated toward the broader canonical portfolio.
